      Governance contract

      • No free-form SQL — agents execute versioned, reviewed templates only.
      • Parameter binding everywhere — every value is a bound parameter; identifiers come from a whitelist.
      • Row caps & truncation flags — queries return bounded results; truncation is explicit.
      • Full audit trail — every executed query is logged with agent, template, row count and duration.
      • Versioned metrics — success_rate v2 excludes unsettled attempts and reports the pending share separately.
      • Fail-closed contracts — invalid events are dead-lettered, never silently coerced.
      • Human approval — decisions stop short of autonomous mitigation.

            Sources
            
    
            Why this matters
            Real sources arrive with different vocabularies (Olist payment types like boleto, not_defined), their own edge cases (missing payments, approval-before-purchase clock skew, split payments, canceled orders) and fail-closed checksum verification. The governed layer accepts them without schema drift — the same templates and agents run unchanged.

            Agent workflow (LangGraph)
            
      
            
    
            
    
            
      
            Layer map
            
      
              
        
            • Producers — synthetic generator (20k attempts/day, seeded hazards) or real adapters (Olist, Upworthy).
              • 
        
            • Transport — in-memory bus for the demo, Kafka for production; identical consumer contract.
              • 
        
            • Ingest — dedup, reorder-safe stage derivation, delayed outcomes, dead-lettering.
              • 
        
            • Store — SQLAlchemy 2.0 on SQLite (demo) / PostgreSQL (Docker), WAL tuned.
              • 
        
            • Governed SQL — template-only, parameterized, row-capped, fully audited.
              • 
        
            • Agents — LangGraph supervisor routes funnel → segments → anomaly → experiment with retry budgets.
              • 
        
            • Hybrid LLM — advisory planning and number-pinned narration; deterministic fallback needs no API key.
              • 
        
            • Surfaces — FastAPI + dashboard, CLI, this static console.
              •

pip install -r requirements.txt
uvicorn paylens.api.main:app --port 8000          # or: python cli.py demo && python cli.py serve
